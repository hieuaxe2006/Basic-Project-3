# 📱 Social Network App (Android - Kotlin)

## 🚀 Giới thiệu

Ứng dụng mạng xã hội cho phép người dùng:

* Đăng bài (text / image)
* Like, comment, save
* Follow người khác
* Chat realtime
* Nâng cấp tài khoản Premium

## 🛠 Công nghệ sử dụng

* Kotlin + Jetpack Compose
* Firebase Authentication
* Cloud Firestore
* ImgBB API (lưu ảnh)
* VNPAY Sandbox (thanh toán)
* OpenAI API (AI features)

## 📱 Tính năng chính

### User:

* Đăng ký / đăng nhập
* Đăng bài
* Like / comment / save
* Follow / unfollow
* Chat realtime
* Profile cá nhân
* Premium (unlimited post)

### Admin:

* Quản lí user
* Duyệt bài
* Thống kê hệ thống

## ⚙️ Cài đặt

1. Clone project
2. Mở bằng Android Studio
3. Thêm file `google-services.json`
4. Run app

## 📦 Build config

* minSdk: 24
* targetSdk: 35
* Kotlin: 2.1.0
* Compose Compiler: 1.5.3
