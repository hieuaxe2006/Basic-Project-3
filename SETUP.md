# ⚙️ Setup Guide

## 🔧 Yêu cầu

* Android Studio
* Firebase account
* ImgBB API key
* VNPAY Sandbox

## 🔥 Firebase Setup

1. Tạo project Firebase
2. Bật Authentication (Email/Password)
3. Tạo Firestore Database
4. Thêm `google-services.json`

## 🖼 ImgBB

* Đăng ký API key
* Dùng để upload ảnh

## ▶️ Run project

* Sync Gradle
* Run app trên emulator hoặc device
