# 🧠 System Design

## 🏗 Kiến trúc

* MVVM (Model - View - ViewModel)
* Client: Android (Jetpack Compose)
* Backend: Firebase

## 🔄 Flow hoạt động

User → App → Firebase Auth → Firestore → Response

## 📡 Modules

* Auth Module
* Post Module
* Social Module (like, comment, follow)
* Chat Module
* Payment Module
* AI Module

## 🔐 Authentication

* Firebase Authentication (Email/Password)

## 💬 Chat

* Firestore realtime listener

## 💳 Payment

* VNPAY Sandbox API

## 🤖 AI

* OpenAI API:

  * Auto tag
  * Gợi ý code
